# FOTOHVN production favicon

The selected booth-portal concept is preserved as
`fotohvn-booth-portal-master.png` and exported at 16, 32, 48, 64, 128, and
256 pixels.

The 16, 32, and 48 pixel files use a reduced FOTOHVN palette for crisp tab
rendering. Those six sizes are embedded in `../../../src/app/favicon.ico` for
the Next.js app.
