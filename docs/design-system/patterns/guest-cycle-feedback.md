# Guest Cycle feedback

Guest stages are zero-scroll and preserve current stage/status, Camera or Photo Strip media, progress/recovery, and primary/safety actions. The Event name appears in Guest Start content but never in a Guest Cycle header. Supporting and celebratory copy is the first content shortened or removed.

## Admission

Guest Start has one dominant Start action. A pre-admission Camera/storage problem becomes Guest Start unavailable: replace Start with the Operator Assistance panel, omit preserved-Capture progress, and show either Retry when recheck can recover or Exit Event when setup must change. Never show disabled Start as the only explanation, and never show Start and Retry together.

## Capture

All four Capture positions remain visible. Countdown is centered and cannot clip. Flash is full-viewport and transient. Preservation uses a compact `Photo saved` overlay without layout movement. `LIVE · MIRRORED` is lowest priority and may disappear in Stress.

## Operator Assistance

Preserve and communicate durable Capture progress. Keep `Please call the operator`, the affected condition, preserved count, and Retry/Exit action. Guest controls are suppressed; failure copy is bounded and actionable.

## Photo Strip

Reserve final image bounds during preparation. Keep the complete aspect ratio. Visible and returning states retain identical geometry; only opacity, time, and progress change. Return is automatic after the canonical 10-second preview.
