# Marketing reel work

Use the relevant reel directory as an independent Remotion project.

## Load

- Read `../../brand/README.md` and the brand documents it routes to (foundation, voice, color, typography, photography, logo, motion, and the video section of `mediums.md`) for FOTOHAVN brand direction. Each reel is an interpretation of `brand/`; use the wordmark masters in `../../brand/assets/`.
- Use `../../website/DESIGN.md` and the live website only as an example of the brand applied to web.
- Read the target reel's README when it contains project-specific editorial decisions.
- Verify composition IDs, dimensions, duration, and commands in the target project's `src/Root.tsx`, `package.json`, and Remotion configuration.

## Media

- Preserve original customer media; place generated proxies and design derivatives in clearly named generated directories.
- Keep the source-to-proxy relationship documented in the project README.
- Treat generated designs as proposals until the selected direction is recorded.

## Verification

Run the target project's lint or type checks, inspect the composition in Remotion Studio, and render representative frames or the requested master before claiming visual completion. Report missing music rights, source-media, or final-export checks explicitly.
