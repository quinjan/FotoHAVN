# FotoHAVN desktop app

This directory is the complete Windows booth module.

- `src/` contains the WinUI application and core behavior.
- `tests/` contains .NET integration and acceptance tests plus source-level contract tests.
- `tools/` contains the UI verification host.
- `prototypes/` contains throwaway desktop product explorations.
- `docs/` contains desktop development, design-system, research, field-test, and UI-verification documentation.
- `design-qa.md` and `design-qa/` contain historical visual evidence.
- `scripts/` contains desktop build, publish, traceability, and verification entry points.

Run desktop commands from this directory. Start with [`docs/local-development-guide.md`](docs/local-development-guide.md) and [`AGENTS.md`](AGENTS.md).
