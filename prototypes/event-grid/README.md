# FotoHAVN Event Grid Prototype

> THROWAWAY PROTOTYPE — Issue #18 visual exploration. Do not ship this code.

Three variants of the saved Events landing page and New Event setup, switchable
with `?variant=A`, `?variant=B`, or `?variant=C` on one prototype route.

Run from the repository root:

```powershell
npm run prototype:event-grid
```

Then open <http://localhost:4178/prototypes/event-grid/>.

The prototype uses only in-memory sample data. Reloading restores the samples.
