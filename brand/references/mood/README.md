# Mood references

**Generated boards.** They are composed in HTML from live-website imagery, `brand/tokens/tokens.json` values, and the real brand fonts, then rendered to PNG. They show the brand world. They are not photographs of new work.

| File | Shows |
| --- | --- |
| `01-material-world.png` | Walnut, curtain, paper, and metal: the physical sources of the palette |
| `02-palette-and-proportion.png` | All nine colors with HEX, RGB, naive CMYK, and the 75 / 20 / ≤ 2 proportion |
| `03-type-pairing.png` | Cormorant Garamond roman + italic (the italic turn) with Manrope roles and actions |
| `04-brand-world-overview.png` | A 3 × 3 overview: wordmark, booth, brand line, palette, print object, guests, website, path, and oversized footer wordmark |
