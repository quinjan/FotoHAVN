# Do and don't references

**Generated boards.** The "do" side of each board uses live-website copy, imagery, and values. The "don't" side is **deliberately off-brand** and must never be reused as a design source.

| File | Do | Don't | Rules |
| --- | --- | --- | --- |
| `01-color.png` | Light-led page, one dark action, a real photograph | Pastel gradients, gold-gradient text, neon pill button | [color.md](../../color.md) |
| `02-typography.png` | Sentence-case serif with the italic turn, quiet sans | Script, condensed, typewriter, title case | [typography.md](../../typography.md) |
| `03-photography.png` | Ink set directly on the luminous curtain, as on the hero | Crushed overlay, neon tint, stickers, emoji | [photography.md](../../photography.md), [color.md](../../color.md) |
| `04-offer.png` | Two inviting paths with text links and ↗ | Pricing cards, "best value" ribbon, crossed-out price, urgency | [components.md](../../components.md#path), [voice.md](../../voice.md#offers) |
| `05-looks.png` | Real prints beside the seven named looks in an option list | Novelty bubbles, emoji, neon rings | [photography.md](../../photography.md#looks), [components.md](../../components.md#option-list) |
| `06-voice.png` | Live-website lines with the italic turn | Hype, jargon, urgency, "Click here" | [voice.md](../../voice.md) |

Prices on the "don't" side of `04-offer.png` are illustrative and are not FOTOHAVN pricing.
