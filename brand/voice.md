# Voice

FOTOHAVN writes the way it photographs: briefly, warmly, and close up. Sentences are short and often come in pairs. The voice invites rather than sells.

Source: the live website copy. Approved lines below are quoted from it.

## Tone

| Is | Is not |
| --- | --- |
| Warm, intimate, gently playful | Salesy, urgent, or loud |
| Short, paired sentences ("Small room. Whole other world.") | Long, wordy, or technical |
| Confident and quiet | Boastful ("the best", "#1") |
| Nostalgic | Retro-costume ("groovy", "old-timey") |
| Inviting ("Ask about your date") | Pushy ("Don't miss out!", "Limited slots!") |

## Signature devices

- **"A little."** Smallness is affectionate and premium: *a little room, a little privacy, a little possibility, a little detour, our little haven, a little moment*. Use it deliberately, usually once per moment.
- **The pair.** Two short sentences, where the second turns or expands the first: "A little privacy. A little possibility." / "A few minutes inside. A memory that stays with you."
- **The italic turn.** In serif headings, the closing phrase carries the emotion and is set in italic: "Keep the moment *close.*", "Look at *you.*" See [typography.md](typography.md#the-italic-turn).
- **Second person.** The copy speaks to "you" and "yours", for example "A little moment. *Yours.*"

## Vocabulary

| Prefer | Avoid |
| --- | --- |
| photographs, prints, keepsakes, Photo Strip, digital strip | content, pics, deliverables, outputs |
| a little room, booth, step inside | kiosk, unit, machine |
| look, photographic finish, filter | effect, preset |
| rent, event rental, pay-per-use visit | package options, solution, activation |
| celebration, moment, together | party (as a brand descriptor), gig |
| ask, find, make, keep | grab, snag, avail, submit |

"Filter" is acceptable, especially in interface steps such as the online booth's "Filters" step. In editorial copy, prefer "look" or "photographic finish".

Use the defined product terms from [`CONTEXT.md`](../CONTEXT.md) exactly, for example Event, Capture, Photo Strip, and Print Sheet. Preserve the scoped distinctions in [`CONTEXT-MAP.md`](../CONTEXT-MAP.md).

## The name

- **Everything a user sees says FOTOHAVN**, in uppercase: websites, apps, reels, decks, print, social, and signage. This applies inside sentence-case copy too ("Rent FOTOHAVN.").
- Internal names are left as they are for now: code identifiers, .NET namespaces and project names (`FotoHavn.App`), the repository (`quinjan/FotoHAVN`), file and folder names, and lowercase technical slugs (`fotohavn.ph`, `deploy/fotohavn/`, `#rent-fotohavn`). Use FOTOHAVN for anything new when the technology allows it.
- Never write "Fotohavn", "FotoHAVN", "Foto Havn", "FOTOHVN", or "FOTO HAVN" anywhere a user will see it.

## Casing

- **Sentence case** for headings, statements, supporting copy, captions, and option names ("Signature Strip", "Soft Monochrome").
- **Uppercase** for eyebrows, navigation, action labels, metadata, and the footer brand line.
- Never use title case for sentences, and never set long text in uppercase.

## Actions

Use short uppercase verb phrases. Each surface has one primary action.

| Action | Use |
| --- | --- |
| `RENT FOTOHAVN` | Primary booking path |
| `EXPLORE THE EXPERIENCE` | Quiet in-page path |
| `EXPERIENCE FOTOHAVN ONLINE`, `MAKE A DIGITAL STRIP` | Online booth |
| `ASK ABOUT YOUR DATE`, `ASK FOR CURRENT DETAILS` | Inquiry via Instagram |
| `SEE THE GOOD COMPANY` | Guest photographs |
| `BACK TO TOP` | Footer |

Follow an action label with a directional arrow glyph that tells the user where it goes: ↓ or ↘ for in-page, ↗ for external, → for the next step, ← for back, ↑ for top. Never write "Click here" or "Learn more" in new copy.

## Offers

- FOTOHAVN offers pay-per-use visits at the booth and event rental by the hour with unlimited prints.
- Frame offers as invitations to ask. Do not lead with prices.
- Never use discount framing, crossed-out prices, "best value" labels, countdowns, or comparison grids.
- Prices and inclusions change. They belong to the interpretation that publishes them, not to this directory.

## Write-then-check

- [ ] Is it short? Could two short sentences replace one long one?
- [ ] Is there an italic turn, and only one, in the serif heading?
- [ ] Is "a little" used deliberately, not on every line?
- [ ] Is there one primary action, and does its arrow match the destination?
